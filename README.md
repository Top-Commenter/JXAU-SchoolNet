# JXAU-SchoolNet · 校园网自动登录

江西农业大学校园网（ePortal）自动登录工具。连上校园网 WiFi 后自动完成网页认证，开机后无需手动打开浏览器登录页。

## 功能

- **开机自启**：注册到 Windows 启动项，开机后后台静默登录，全程无窗口
- **自动检测**：每 30 秒巡检网络状态，断网自动重连，故障自动重试
- **多运营商**：中国移动 / 中国电信 / 中国联通
- **系统托盘**：图标颜色实时反映网络状态，右键菜单快速操作
- **免安装**：单个 exe 即可运行，无需安装 Python 或任何依赖

## 快速开始

1. 从 [校园网自启-分发](./校园网自启-分发) 文件夹下载 `校园网自启.exe`
2. 放到固定可写目录（如 `D:\校园网自启\`），双击运行
3. 填写账号、密码，选择运营商，点 **保存**
4. 登录成功后按提示开启开机自启即可

> 详细使用说明见 [使用说明.md](./校园网自启-分发/使用说明.md)

## 托盘状态

| 颜色 | 含义 |
|------|------|
| 🟢 绿 | 已联网 |
| ⚪ 灰 | 未联网（检查 WiFi） |
| 🟠 橙 | 登录中 |
| 🔵 蓝 | 待处理（未配置或密码错误） |
| 🔴 红 | 异常 |

## 技术栈

- Python 3.13 + tkinter（GUI）
- PyInstaller（单文件打包）
- pystray + PIL（系统托盘）
- ePortal 协议（portal 801 端口，非旧版 drcom）

## 项目结构

```
├── core/          # 核心逻辑
│   ├── detector.py    # 网络探测 + portal 自动发现
│   ├── drcom.py       # ePortal 登录协议
│   ├── monitor.py     # 守护线程（巡检/重试/状态机）
│   ├── config.py      # 配置读写（原子写入）
│   ├── autostart.py   # 注册表开机自启
│   └── log.py         # 日志轮转
├── gui/           # 界面层
│   ├── app.py         # 主窗口
│   └── tray.py        # 系统托盘
├── main.py        # 入口
└── 校园网自启.spec   # PyInstaller 打包配置
```

## 隐私

- 账号密码仅保存在本机 `config.json`（base64 编码，非加密）
- 登录请求只发往校园网内网认证服务器，与浏览器手动登录同一接口
- 分发时**只发 exe**，切勿附带 `config.json`（含个人凭据）
