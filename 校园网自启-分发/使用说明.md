# 校园网自动登录 · 使用说明

**当前版本**：v1.0.0  
**发布日期**：2026-10-12  
**适用系统**：Windows 10/11、macOS 11+

### 更新历史

| 版本 | 日期 | 更新内容 |
|------|------|----------|
| v1.0.0 | 2026-10-12 | 首个正式版：ePortal 协议自动登录、开机自启、系统托盘、多运营商支持、跨平台架构重构（新增 macOS 支持） |

---

一个开机后自动登录校园网的小工具。连上校园网 WiFi 后，程序会自动检测"未登录"状态并用你填写的账号密码完成网页认证，无需每次手动打开浏览器登录页。

- 免安装：单个可执行文件即可运行（Windows 为 `校园网自启.exe`，macOS 为 `校园网自启.app`），**不需要安装 Python**
- 每个用户使用**自己的校园网账号密码**，在主界面填写，保存在本机
- 支持：中国移动 / 中国电信 / 中国联通 三种账号类型

---

## 系统要求

| 系统 | 版本 | 可执行文件 | 开机自启方式 |
|------|------|-----------|-------------|
| Windows | 10 / 11 | 校园网自启.exe | 注册表启动项（--hidden 静默） |
| macOS | 11 Big Sur 及以上 | 校园网自启.app | launchd（~/Library/LaunchAgents） |

> macOS 版需在 Mac 上用 `校园网自启-mac.spec` 重新打包生成，Windows 打出的 .exe 不能在 Mac 运行。源码运行时两平台均可 `python main.py` 启动。

## 一、分发给其他用户（发给同学前必读）

程序目录中**只能发送 `校园网自启.exe` 这一个文件**：

| 文件 | 能否随 exe 一起发 | 原因 |
|------|------------------|------|
| `校园网自启.exe` | ✅ 发送这个 | 程序本体 |
| `config.json` | ❌ **必须删除后再发** | 里面是**你自己的账号和密码**（base64 编码，可被还原），发给别人等于泄露账号 |
| `log.txt` | ❌ 不要发 | 运行日志，含本机 IP 等信息，对别人无用 |

接收方第一次运行时程序会让他填写自己的账号，并在 exe 同目录自动生成属于他的 `config.json`。

> 用 U 盘 / 压缩包 / 聊天软件传输同理：**只发 exe**。

## 二、首次使用（每个账号第一次配置，约 30 秒）

1. 把 `校园网自启.exe` 放到一个**可写的、固定的文件夹**，例如桌面或 `D:\校园网自启\`。
   - 不要放在压缩包里直接双击运行；不建议放 `C:\Program Files`（系统目录可能无法写配置）。
2. 先连上校园网 WiFi（如 `JXAU-Stu`）。
3. 双击 `校园网自启.exe` 启动，弹出主窗口：

   | 界面项 | 填写说明 |
   |--------|----------|
   | **账号** | 你的校园网账号（学号/工号），**只填账号本身**，不要加 `@cmcc` 之类后缀 |
   | **密码** | 校园网登录密码（输入框显示为 `***`） |
   | **运营商** | 按下表选择，程序会自动拼对应后缀 |
   | **开机自启（后台静默运行）** | 勾选后，每次开机自动在后台登录，无需任何操作 |

4. 点击 **保存**，程序会立即尝试连接（在账号或密码输入框直接按**回车**等效），状态灯变绿即登录成功。
5. **首次登录成功后会弹出"是否开启开机自启？"**，点"**是**"以后每次开机即全自动，无需再操作（每个账号只会被询问一次；之后也可随时用界面勾选框更改）。
6. 关闭窗口时点右上角 **× 只是隐藏到托盘**，程序仍在后台运行；需要完全退出请在托盘图标右键 → **退出**。

> 小技巧：勾"**显示密码**"可核对密码输入；账号框下方灰字提示"无需 @后缀"，后缀由运营商下拉框自动拼接。

### 运营商与账号类型对照

| 下拉选项 | 适用账号 | 程序实际提交的账号形式 |
|----------|----------|------------------------|
| 中国移动 | 办理了移动套餐的账号 | `账号@cmcc` |
| 中国电信 | 办理了电信套餐的账号 | `账号@telecom` |
| 中国联通 | 办理了联通套餐的账号 | `账号@unicom` |

不确定选哪个时，与你**平时用浏览器登录网页时选择的运营商一致**即可；选错会报账号无法识别之类错误，改选后重新保存。

## 三、日常使用

- **已勾选开机自启**：开机登录 Windows 后程序自动后台启动（屏幕无窗口，只有右下角托盘图标）。程序一启动就会立即检测一次，此后每 30 秒巡检；待 WiFi 关联完成、检测到未登录后通常几秒内自动完成认证（最坏约一个巡检周期 30 秒）。
- **托盘图标颜色**：

  | 颜色 | 含义 | 你需要做什么 |
  |------|------|--------------|
  | 🟢 绿色 | 已联网 | 无需操作 |
  | ⚪ 灰色 | 未联网（WiFi 未连接等） | 检查 WiFi |
  | 🟠 橙色 | 正在登录 | 等待，通常 1~2 秒 |
  | 🔵 蓝色 | 待处理：未填账号密码，或账号/密码错误后已暂停 | 打开主界面检查配置 |
  | 🔴 红色 | 登录异常 | 看主界面提示或 `log.txt` |

- 托盘右键菜单：**显示主界面**（双击图标也可）/ **立即连接** / **退出**。

---

## 四、更换账号 / 修改密码

1. 双击托盘图标打开主界面（或重新运行 exe，再点"显示主界面"）。
2. 修改账号 / 密码 / 运营商。
3. 点击 **保存**，程序会立即按新配置尝试连接。
4. 换号前若原账号仍在线，建议先在校园网网页上注销原账号，避免提示"该账号已在别处登录"。

---

## 五、开启 / 关闭开机自启

- 主界面勾选 **开机自启（后台静默运行）** 即开启，取消勾选即关闭，**不需要管理员权限**。
- 开启的本质：在当前 Windows 用户的注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 写入一条启动项，开机后以 `--hidden` 静默方式启动本 exe。
- 移动了 exe 位置后，重新勾选一次开机自启即可刷新路径。
- WiFi 本身也要是"自动连接"（在 Windows 的 WLAN 属性里设置），否则开机后只启动了程序但没有连 WiFi。

## 六、常见问题

**Q：双击 exe 弹出 SmartScreen "Windows 已保护你的电脑"？**
A：程序没有购买代码签名证书，属正常现象。点"更多信息" → "仍要运行"。

**Q：双击后很久才出窗口？**
A：单文件版首次启动需要几秒解压，属正常现象。

**Q：蓝色"待处理"一直不变？**
A：两种原因：① 还没填账号密码；② 之前账号或密码错误，程序已暂停反复尝试以免账号被风控。改正账号密码后点**保存**或**立即连接**即可恢复。

**Q：提示"该账号已在别处登录"？**
A：同一账号在手机/另一台电脑上在线。下线其他设备，或等几分钟后点"立即连接"。

**Q：提示"账号不存在 / 密码错误 / 账号已停机"？**
A：核对账号、密码、运营商三项；停机/欠费需先到运营商或网络中心处理。

**Q：提示"未能从校园网重定向获取登录参数"？**
A：断开 WiFi 重连一次，再点"立即连接"。

**Q：灰灯，日志显示"无网络连接"？**
A：确认已连上校园网 WiFi 且信号正常；程序每 10 秒会自动重试。

**Q：多个 Windows 用户共用一台电脑？**
A：开机自启项写在各自的用户配置里，需要哪个用户开机自启，就登录该用户后在程序里勾选一次。

**Q：程序会把我的账号密码发到哪？**
A：只向校园网内网的认证服务器（portal，801 端口）发起登录请求，与浏览器手动登录是同一个接口；配置只保存在本机 exe 同目录的 `config.json`。

## 七、数据与隐私说明

- 配置文件：`校园网自启.exe` **同目录**下的 `config.json`。
- 密码在文件中仅做 **base64 编码（防随手可见，不是加密）**，任何能打开该文件的人都可以还原密码。请勿把该文件发给他人、不要上传到公开位置。
- 运行日志：同目录 `log.txt`（超过 512KB 会自动轮转为 `log.txt.old`），排查问题时可查看。
- 卸载程序不会自动删除这两个文件。

---

## 八、卸载 / 彻底删除

1. 托盘右键 → **退出**，停止程序。
2. 取消勾选"开机自启"（或直接删除注册表项 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `CampusNetAutoLogin`）。
3. 删除整个程序文件夹（含 exe、`config.json`、`log.txt`）。
